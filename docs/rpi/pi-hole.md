# Pi-hole and other project ideas

These are project references and starting points, not a complete installation
procedure. Follow the projects' current official instructions, and review
network and DNS changes before applying them to your home network.

## Pi-hole

[Pi-hole](https://pi-hole.net/) is a network-level DNS filtering project. The
[Raspberry Pi Foundation tutorial](https://www.raspberrypi.com/tutorials/running-pi-hole-on-a-raspberry-pi/)
is a starting point for installation. Before enabling it for a whole network,
make sure you know how to restore the router's previous DNS settings in case
devices lose name resolution.
